# Taller-Estructuras-Lineales
Estudiante: Ronny Farid Guevara Galvis
Materia: Tecnología en Desarrollo de Software

Descripción
Solución al taller de estructuras lineales: arreglos unidimensionales, arreglos bidimensionales (matrices) y ArrayList, implementado en Java siguiendo, cada ejercicio separa sus responsabilidades en métodos de generación de datos e impresión de resultados.

Estructura del proyecto
Taller-Estructuras-Lineales
├── src/
│   ├── arreglos/       (ejercicios 1 a 5 — arreglos )
│   ├── arraylist/      (ejercicios 6 a 9 — ArrayList)
│   │   
│   └── matrices/       (ejercicios 11 a 15 — arreglos bidimensionales)
└── README.md
Instrucciones para ejecutar
Ejercicios de arreglos, arraylist y matrices (VS Code)
Abre la carpeta src en Visual Studio Code (con el Extension Pack for Java instalado).
Cada clase tiene un método main; ejecútala directamente desde el editor (botón "Run" sobre el método main) o por consola
Los ejercicios que piden datos por teclado (Scanner) los solicitarán en consola.
